# Project artwork

`docs/assets/fenix-panorama.png` is an original AI-generated illustration made
for this community project with the built-in OpenAI image-generation tool. It
shows an unbranded A320-family aircraft above the Alps at golden hour. It is
project artwork, not a simulator screenshot or evidence of game compatibility.
The original Flightdeck cover informed the visual direction; its image was not
copied or used as an edit target. The artwork is included under the project's
MIT license.

`docs/assets/mark.svg` is an original, hand-coded two-face aircraft mark for the
Linux patch community project. It is not an official Fenix Simulations logo.
It is included under the same MIT license.
